# Official references

These links are starting points, not a substitute for checking the current
version of a component before changing a live system.

## Home Assistant and voice

- [Home Assistant documentation](https://www.home-assistant.io/docs/) — core
  concepts and supported configuration.
- [Assist voice assistant](https://www.home-assistant.io/voice_control/) —
  supported voice architecture.
- [Assist best practices](https://www.home-assistant.io/voice_control/best_practices) —
  naming, areas, and reliable conversation design.
- [Aliases in Assist](https://www.home-assistant.io/voice_control/aliases) —
  human-facing names.
- [Expose devices to Assist](https://www.home-assistant.io/voice_control/voice_remote_expose_devices/) —
  controlling the exposure boundary.

## Platform and operations

- [Proxmox VE documentation](https://pve.proxmox.com/pve-docs/) — hypervisor,
  storage, backup, and firewall references.
- [Debian documentation](https://www.debian.org/doc/) — base operating-system
  administration.
- [Ansible documentation](https://docs.ansible.com/) — repeatable configuration
  and check-mode concepts.
- [Docker Compose documentation](https://docs.docker.com/compose/) — service
  definition and validation.
- [Git documentation](https://git-scm.com/doc) — versioned source of truth.
- [Tailscale documentation](https://tailscale.com/kb) — private connectivity
  and access controls.

## Protocols and safety context

- [MQTT specification](https://mqtt.org/mqtt-specification/) — messaging
  concepts for compatible devices.
- [Matter documentation](https://csa-iot.org/developer-resource/matter/) —
  standards context and official developer resources.
- [Thread Group](https://www.threadgroup.org/) — Thread protocol resources.
- [OWASP threat modeling](https://owasp.org/www-community/Threat_Modeling) —
  a general way to reason about trust boundaries.

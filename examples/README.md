# Generic examples

These examples are deliberately small and fictional. They demonstrate the
shape of a source-of-truth repository without pretending to know another
household's hardware or preferences.

- [`context.yaml`](context.yaml) — vocabulary and boundaries.
- [`inventory.yaml`](inventory.yaml) — role-oriented capabilities, not
  identifiers.
- [`proposal.md`](proposal.md) — a bounded change proposal.
- [`observed.md`](observed.md) — dated evidence without private data.
- [`demo/`](demo/) — a runnable offline fallback with exactly six generic
  artifacts: context, inventory, proposal, diff/change, verification, and
  restore evidence.

Copy them into a private project and replace the values after discovery.

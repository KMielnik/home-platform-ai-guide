# Talk package

The editable deck is [`slides.md`](slides.md). It is Markdown with one
heading per slide and speaker notes in HTML comments. It can be edited in any
text editor or adapted to a preferred presentation tool. No renderer is
required to read or present it.

Supporting material:

- [`abstract.md`](abstract.md) — short abstract and meetup description.
- [`timing.md`](timing.md) — section timing and a 30-minute / 45-minute mode.
- [`demo-plan.md`](demo-plan.md) — live demo, preparation, and offline
  fallback.
- [`references.md`](references.md) — links used in the talk.

The deck uses generic examples. Replace them only in a private copy, then run
the privacy scanner before sharing.
